Vulkan Initialization
Instance
instance.h / .cpp
Creates the VkInstance — the connection between the app and the Vulkan library. Configures validation layers and instance extensions.
Debug Messenger
debug_messenger.h / .cpp
Validation layer callback. Intercepts Vulkan errors, warnings, and performance issues during development.
Surface
surface.h / .cpp
Platform-specific window surface (VkSurfaceKHR) created via GLFW. The target for rendered image presentation.
Physical Device
physical_device.h / .cpp
Enumerates GPUs, checks queue family support (graphics, present), required extensions, and swap chain adequacy.
Logical Device
logical_device.h / .cpp
Creates VkDevice with required queues and features. The primary interface for all GPU operations.
Vulkan Rendering Pipeline
Swap Chain
swap_chain.h / .cpp
Queue of images for presentation. Handles format selection, present mode (V-Sync), extent, and recreation on resize.
Image Views
image_views.h / .cpp
VkImageView wrappers describing how to access swap chain images (format, aspect, mip levels).
Render Pass
render_pass.h / .cpp
Defines attachment descriptions (color + depth), subpasses, and subpass dependencies. Blueprint for rendering operations.
Graphics Pipeline
graphics_pipeline.h / .cpp
Immutable pipeline object: shader stages, vertex input, rasterization, MSAA, depth test, blending. Created once, bound at draw time.
Framebuffers
framebuffers.h / .cpp
Bind image views to render pass attachments. One framebuffer per swap chain image.
⬇ draw commands flow ⬇
Command & Synchronization
Command Pool
command_pool.h / .cpp
Allocator for command buffers, tied to a queue family. Manages memory for recorded GPU commands.
Command Buffers
command_buffers.h / .cpp, CommandBuffer.h / .cpp
Record draw calls, pipeline binds, descriptor set binds, push constants. Submitted to GPU queues for execution.
Sync Objects
sync_objects.h / .cpp
Semaphores (GPU-GPU sync: image acquired → render done) and fences (CPU-GPU sync: wait for frame completion). Enables multi-frame-in-flight.
Descriptor System
Descriptor Set Layout
descriptor_set_layout.h / .cpp
Defines the shader binding interface — which binding points expect UBOs, samplers, etc. Must match GLSL layout qualifiers.
Descriptor Pool
descriptor_pool.h / .cpp
Pre-allocates a pool of descriptors by type (uniform buffer, combined image sampler). Descriptor sets are allocated from here.
⬇ resources bound via descriptors ⬇
GPU Resources
Vertex Buffer
vertex_buffer.h / .cpp
Device-local buffer holding vertex data (position, normal, UV, color). Uses staging buffer for host→device transfer.
Index Buffer
index_buffer.h / .cpp
Triangle index data for indexed drawing, reducing vertex duplication. Also staged to device-local memory.
Uniform Buffers
uniform_buffers.h / .cpp
Per-frame data (MVP matrices, light params) mapped to host-visible memory. Updated each frame before draw submission.
Textures
texture.h / .cpp, texture_image.h / .cpp, texture_sampler.h / .cpp
Image loading → VkImage creation → layout transitions → mipmap generation → VkSampler (filtering, wrap modes). Full texture pipeline.
Depth Resources
depth_resources.h / .cpp
Depth buffer (VkImage + VkImageView) for depth testing. Format selected based on GPU support (D32/D24).
Scene & Assets
Asset Types & Loading
asset_types.hpp / .cpp, assets.h
Loads 3D models via tiny_gltf (glTF 2.0) and tiny_obj (OBJ). Parses vertices, indices, materials, textures from files.
Camera
camera.h / .cpp
Computes view matrix (lookAt) and projection matrix (perspective). Handles input for movement and rotation.
Angles
Angles.h
Rotation representation utilities (Euler angles, conversions). Used by camera and transform systems.
Shaders
shaders/ directory
GLSL vertex/fragment shaders compiled to SPIR-V. Handle MVP transforms, texture sampling, lighting calculations on the GPU.
⬇ game logic layer ⬇
Entity Component System
flecs (ECS Framework)
libraries/flecs/
Data-oriented architecture. Entities = IDs, Components = data structs (Transform, Mesh, RigidBody), Systems = queries that iterate matching entities. Cache-friendly and scalable.
Physics
ReactPhysics3D
libraries/reactphysics3d/
Rigid body dynamics, collision detection (broad/narrow phase), collision shapes. Physics world stepped each frame, transforms synced to ECS entities.
Editor
Editor GUI
EditorGUI.h / .cpp
Dear ImGui-based immediate mode editor. Inspect/modify entities, transforms, components at runtime. Rendered as an overlay via Vulkan ImGui backend.
⬇ foundation ⬇
Infrastructure & Build
Cleanup Stack
cleanup_stack.h / .cpp
Deferred destruction pattern. Vulkan resources must not be freed while GPU is using them. Queues deletions for safe execution after sync.
Defines & Conventions
defines.h / .cpp, conventions.txt
Global constants (MAX_FRAMES_IN_FLIGHT, validation layer names), macros, and project coding standards.
Build System
CGProject.vcxproj, _maker.ps1
VS2022 / v143 / C++17 / x64. Configs: Debug, Release, Build Assets. Links: vulkan-1.lib, glfw3.lib, reactphysics3d.lib. _maker.ps1 compiles shaders to SPIR-V.
Libraries
libraries/
GLM (math), GLFW 3.3.8 (windowing/input), Dear ImGui (GUI), tiny_gltf/tiny_obj (model loading), flecs (ECS), ReactPhysics3D (physics), stb (image loading).
